# 管理画面から試聴機を準備する

管理操作はPC、音源の保存と再生は試聴機で行います。初回準備と更新はネット接続が必要です。音源はAWSへ登録したものを試聴機が取得します。

## 作品と入口を確認する

PCの管理画面で「試聴機を準備する」を開きます。試聴用FLACの関連付け画面からも進めます。登録専用のローカル接続から開いた場合は、表示される正式な管理画面へ移動して通常の管理認証を行います。ローカル接続のURLを試聴機へ渡しません。

公開済みで確定済みFLACを関連付けた全作品が配布対象です。下書きや音源未設定は画面の理由を確認し、作品編集または[FLAC登録](ADMIN_AUDIO_REGISTRATION.md)へ戻ります。ここでは作品を自動公開せず、端末ごとの配布対象も選びません。

「別の試聴機で開く」のURLを試聴機のブラウザーへ入力するか、QRを読み取ります。QRには入口URLだけが入っています。「この端末で開く」はPC自身への保存操作になります。

## 接続を許可して保存する

1. 試聴機で端末名を確認し、「管理画面と接続」を押します。
2. 試聴機の接続コードを、PCの管理画面へ入力して照合します。手元の試聴機のコード・端末名と一致することを確認し、取得用認証の期間を指定して許可します。管理キーを試聴機へ入力する必要はありません。
3. 試聴機に許可の表示が出たら「アプリと音源を保存」を押します。許可や作品への関連付けは、試聴機への保存完了を意味しません。保存結果は試聴機の画面で確認します。
4. 新版の保存後は全ての試聴タブを閉じ、開き直します。保存が完了した版へ切り替わり、作品を選べます。保存失敗時に旧版を使っている場合は、表示を確認して再準備します。
5. 新規音源の解析が必要な場合は管理メニューの「この端末で主旋律・和音を解析」から対象作品を選び、「解析して保存」を実行します。音源の保存と解析の保存は別です。
6. 通信を切り、対象作品の選択・再生を確認します。初回の展示開始では、試聴機内の展示操作を保護する管理PINを設定します。このPINはPCの管理キーや端末のロック解除とは別です。保存済み音源の通常再生には接続操作は不要です。

更新は管理メニューを解除して「配布物を準備する」から同じ操作へ戻ります。取得用の認証情報はブラウザーへ永続保存しないため、新しい準備セッションでは再接続します。

## 接続に失敗したとき

- コードが期限切れ・拒否された場合は試聴機から新しい接続を始めます。回数制限の表示が出た場合は表示された待機時間の後に操作します。
- 許可後に受取応答を確認できない場合は、PCでコードを再照合し、発行済みなら確認用IDと端末一覧を対応付けて失効します。その後、試聴機から新しい接続を開始します。自動で何度も発行し直す操作はありません。
- 端末認証の失効は新しい取得を止める操作です。保存済み音源を消去する操作ではありません。
- 画面を閉じる前に、取得・保存・新版への切替のどこまで進んだかを表示で確認します。PCの端末一覧では試聴機の保存状態を遠隔確認できません。

実際の入口URL、配布版、運用設定と実機での結果は非公開の運用記録で管理します。
