# 作成済みFLACを管理画面から登録する

対象は、ノートPCの管理接続から作成済みFLACを登録し、作品の試聴用クロスフェードへ関連付ける操作です。クロスフェードの作成は外部アプリで済ませておきます。

この文書と画面はv1.101の実装候補です。実環境の接続・候補配布・持参PCでの受け入れが完了するまでは、運用可能と判断しないでください。接続先、アカウント、鍵の取得方法、実行版は非公開の運用手順を参照します。

## 初回準備と接続

WindowsのノートPCに、Node.js 24、AWS CLI v2、Session Manager plugin、対応ブラウザーを準備します。初回のインストールと管理権限の設定は、運用担当が非公開手順に従って行います。管理画面の版と接続補助の版をそろえます。

1. ネットワークへ接続し、登録するFLACをローカルに置きます。ファイルは空でない256MiB以下とし、登録中に編集しないでください。
2. 運用手順の接続起動を行います。AWS認証が期限切れの場合は、認証を開く前に案内します。本人が準備できた後、既定の外部ブラウザーでサインイン・MFAを完了します。認証値をチャットへ送る必要はありません。
3. 接続補助が表示したローカルURLを既定ブラウザーで開きます。接続補助のウィンドウは操作が終わるまで開いておきます。
4. 通常の管理認証で管理画面を開きます。AWSの接続認証と管理画面の認証は別です。管理キーを接続補助へ自動注入する構成ではありません。

接続補助は同じPCからだけ利用できます。表示されたURLを他の端末へ共有しても使えません。この入口はFLAC登録に必要な経路だけを通すため、記事編集や公開・削除などは通常の管理入口を使います。

## 登録と作品への関連付け

1. 作品一覧で対象作品の「試聴用FLAC」を開き、作品名と現在の音源設定を確認します。
2. 「作成済みFLAC」で原本を選び、「FLACを登録する」を押します。
3. ファイル照合、送信、サーバー検査を待ちます。大きいファイルは時間がかかるため、PCをスリープさせず、接続を維持します。
4. 登録状態が `CONFIRMED`、原本の照合が「選択したファイルと一致」になったことを確認します。
5. 「この作品の試聴用FLACに設定」を押します。設定済みの場合は「現在の試聴用FLACをこの音源に変更」と表示され、押すと試聴用音源が置き換わります。
6. 保存結果の確認メッセージと「現在の試聴用FLAC」を確認します。音源は非公開のままで、公開試聴URLは変わりません。

登録と関連付けは別の操作です。送信成功だけでは作品の設定は変わりません。試聴端末に取得済みの配布物へ反映する操作は、この登録操作の完了とは別です。

続けて「試聴機を準備する」を開き、[試聴機への接続・保存手順](LISTENING_PREPARATION.md)へ進みます。管理操作はPCで行い、試聴機では試聴アプリを開きます。

## 切断・失敗時の復旧

| 表示・状況 | 次に行う操作 |
| --- | --- |
| 通信切断、待機期限超過、送信を中断 | 接続を戻して「登録状態と作品の設定を確認」を押します。サーバー側の処理が完了している可能性があるため、自動再送はしません。 |
| `PENDING` | まだ確定を確認できません。処理継続の可能性があるので、状態を再照会します。同じ予約への再送ボタンはありません。 |
| `INSPECTED` / `ABANDONED` かつ原本一致 | 「保存済み原本の確定を復旧」を押し、状態を確認します。再アップロードは行いません。復旧できない場合は運用担当が調査します。 |
| `CONFIRMED` かつ原本一致 | 送信応答を失っていた場合でも、照会で確認できた原本を作品へ設定できます。 |
| 原本不一致、状態未確認 | 関連付けを進めず、運用担当へ登録IDと表示された状態を伝えます。秘密値や原本ファイルをログへ貼らないでください。 |
| 認証期限切れ | 管理画面へ再認証し、状態を照会します。同じタブには登録IDと原本の照合値が残ります。 |
| 画面の再読込 | 同じタブで再認証すると登録状態を照会します。原本のバイト列は保存していません。タブを閉じた後の復旧は、控えた登録IDと元のFLACを使って運用担当が確認します。 |
| 作品設定の競合・結果不明 | 表示された現在の設定と目的の音源を比較します。更新は自動再試行しません。変更する場合だけ、最新状態を確認したうえでもう一度設定します。 |
| `EXPIRED`、または原本一致を確認した `CONFIRMED` から新しいファイルを使う | 「別のFLACを登録する」から新規登録します。前の音源や作品設定を削除する操作ではありません。未確認・未確定・原本不一致の間はこの操作を無効にし、復旧用の登録ID・照合値を保持します。 |

最初の予約作成の応答を失い、登録IDを受け取れなかった場合は原本の送信を始めません。画面で自動再予約せず、接続を確認してから新しい登録を明示的に開始します。

## 終了

1. 作品の設定結果を確認して管理画面からログアウトします。
2. 接続補助を終了し、ローカルURLが開けなくなったことを確認します。
3. 終了確認に失敗した場合は、運用担当が今回の管理セッションだけを終了します。他の作業の接続をまとめて停止しないでください。

## 実装と検証の境界

汎用接続補助は `scripts/admin-audio-bridge.mjs`、管理画面は `/admin/albums/audio/` です。実行補助は接続先サイトと、起動済みトンネルのloopbackポート、メモリ上のorigin検証値を渡して `startAudioBridge` を呼び、戻り値の `close` で終了します。機能ゲート、WAF、料金プラン、管理認証の方式は変更しません。

ローカルのソケット試験・画面試験は認証境界と操作の制御を確認するものです。AWS接続、実FLACの検査・保存、持参PCのブラウザーでの操作は別途受け入れます。
